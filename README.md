## Simple profile converter ##

This program converts old profile configurations files of [Throne VPN](https://github.com/throneproj/Throne/). 

To run it, you need to specify the path to the directory containing JSON profile configuration files.
This will create files for subsequent import into the new version of Throne 1.1.1 VPN.

For run this project need use NET8.0

**Supported profile types**: shadowsocks, vmess, vless, trojan, hysteria2
